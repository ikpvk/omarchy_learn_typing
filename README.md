# Sofle Studio

A native, offline Linux typing trainer for the 58-key Sofle split keyboard. A
drawing of the Sofle lights up the next key, plus any Shift or layer key to
hold. It starts from the stock QMK Sofle keymap, which you can edit to match
your firmware, and follows your Omarchy theme and font.

The app is in [`linux_app`](linux_app/). See its [README](linux_app/README.md)
for requirements, usage, keymap editing and uninstall instructions.

With GTK 4 and PyGObject installed, launch it from this repository's root:

```sh
./linux_app/run.sh
```
